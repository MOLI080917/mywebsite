## 5. 排除清单（明确不做什么）

1. **不做博客 / 文章系统**，不做文章列表与详情页。
2. **不做暗色/浅色主题切换**：全站固定为以近白为主、近黑反色分区的单一黑白红方案（具体角色见阶段 1）。
3. **不使用色板之外的任何色相**，不引入彩虹、渐变彩色（原始效果里的彩虹类动效必须去色，只保留黑白红 + 透明度）。
4. **不放真人照片**（用户未提供，且与锐利排版风格不符）；作品视觉用纯 CSS/排版/占位图形表达，预留 `assets/images/` 供日后替换。
5. **不堆砌动效**：每个区域最多一个主导动效；动效可被 `prefers-reduced-motion` 关闭，关闭后内容仍完整。
6. **不使用构建工具/框架**：原生 HTML + CSS + JS，仅通过 CDN 引入 GSAP（含 ScrollTrigger），双击 `index.html` 即可运行。
7. **不写虚假的对外承诺与夸大头衔**：示例文案贴合"中职在读学生"的真实水平，以学习能力和作品潜力取胜。
