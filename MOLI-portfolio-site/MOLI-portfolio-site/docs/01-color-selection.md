# 阶段 1 · 配色选定与色板定义

> 回归基准：`docs/00-theme-anchor.md`。三个气质关键词：**锐利 Sharp / 极客 Geek / 真诚 Real**。

---

## 1. 四套配色匹配度评估

| 色板 | 风格 | 与本主题匹配度 | 结论 |
|---|---|---|---|
| 001 冷调蓝灰 | 冷静克制·科技感 | 中：够"极客"，但偏温和、缺冲击力，与"锐利"不符 | 不选 |
| 002 深绿自然 | 生机沉稳·森林系 | 低：自然系与"强烈创意·艺术感"方向相反 | 不选 |
| **003 黑白红** | **强烈对比·现代冲击** | **高：黑=锐利理性、白=真诚留白、红=记忆焦点，三词全覆盖** | **选定** |
| 004 灰紫粉 | 柔和优雅·复古温暖 | 低：柔和方向与"锐利"冲突 | 不选 |

> 用户在阶段 0 已明确选择"强烈创意·艺术感"，该选项即对应 003，故直接锁定，不再回退。

## 2. 选择理由（每条关联主题锚定）

1. **服务"锐利"**：`#000103` 与 `#FFFFFA` 构成接近纯黑/纯白的极限明度对比（正文对比 20.8:1），天然带海报/构成主义的硬边冲击力，第一眼就有锋芒。
2. **服务"极客"**：无彩色的黑白基底像终端/代码编辑器，唯一的红像报错提示与编译焦点，契合"计算机专业学生"的技术隐喻，而不显得花哨。
3. **服务"真诚"**：只用五个颜色、近白大面积留白，不靠复杂渐变和装饰堆砌，让作品本身说话；红色被严格限制为"行动焦点"，避免营销感和廉价感。
4. **换一套气质会明显改变**：换成 001 蓝灰会立刻变"温和商务"，换成 004 会变"柔和生活方式"——证明本配色确实在为主题服务，而非可有可无。

## 3. 五个色值的角色定义（一一对应，无遗漏无新增）

| 变量 | 色值 | 角色 | 使用范围 |
|---|---|---|---|
| `--color-bg` | `#FFFFFA` | 页面主背景（纸感近白） | body、浅色分区 |
| `--color-bg-sub` | `#333138` | 次背景 / 反色分区 / 深色卡片 | 深色 Section、作品卡、页脚 |
| `--color-text` | `#000103` | 主文字（近黑） | 浅色背景上的全部正文与标题 |
| `--color-text-sub` | `#515052` | 次文字 / 说明（中灰） | 浅色背景上的辅助、标签、时间 |
| `--color-accent` | `#FF312E` | **全站唯一强调色（正红）** | 见下方"强调色单一角色"边界 |

### 强调色（红）的单一角色边界

红色在全站只承担**一个语义角色：「焦点与行动」（focus & action）**，具体只出现在：
- 主 CTA 按钮**底色**（按钮文字用近黑 `--color-on-accent`，对比 5.70:1）；
- 当前导航项的指示块 / 导航 hover 下划线；
- 键盘焦点环（focus-visible ring）；
- 超大号展示性数字或单个关键词（属图形元素，非正文，满足 3:1 图形对比）。

**红色不得**用于：整段正文文字、大面积页面背景、彩色渐变、同时既做文字色又做背景色。需要"强调一段文字"时，优先用近黑粗体 + 红色短下划线/红色块衬底，而不是把整串字染红。

### 反色（深色）分区规则
深色分区以 `#333138` 为底：主文字用 `#FFFFFA`（对比 12.8:1），次文字用近白 72% 透明度（`--color-text-on-dark-sub`，仍是同色相调透明度，合规）。近黑 `#000103` 用于最深的页脚/导航底。

## 4. WCAG 对比度核算（相对亮度 → 对比比）

| 前景 / 背景 | 比值 | 判定 | 用途 |
|---|---|---|---|
| `#000103` / `#FFFFFA` | **20.8:1** | AAA | 主正文 |
| `#515052` / `#FFFFFA` | **7.99:1** | AA（正文） | 次文字 |
| `#FFFFFA` / `#333138` | **12.8:1** | AAA | 深分区文字 |
| `#FF312E` / `#FFFFFA` | 3.65:1 | 仅大字/图形(≥3:1) | 红色只做展示/UI，不做小号正文 |
| `#000103` / `#FF312E` | **5.70:1** | AA | **红按钮上的文字用近黑** |
| `#FFFFFA` / `#FF312E` | 3.65:1 | 不达标 | 故红按钮**不用白字** |

结论：所有承载正文的组合均 ≥ 4.5:1；红色的使用方式被对比结果反向约束（红底配近黑字、红字只作大号展示）。

## 5. 衍生变量（仅透明度，不改色相）

- `--color-accent-hover: rgba(255,49,46,.82)` 强调悬停；
- `--color-border: rgba(0,1,3,.12)` 近黑 12% 边框；
- `--color-overlay: rgba(255,255,250,.6)` 浅色遮罩；
- `--color-scrim: rgba(0,1,3,.55)` 深色遮罩（移动菜单）；
- `--color-text-on-dark-sub: rgba(255,255,250,.72)` 深分区次文字。

变量已写入 `css/variables.css`，同时定义了字体、字阶（clamp 流式）、8pt 间距阶、硬边圆角与硬投影、统一动效缓动/时长，供后续阶段直接引用。
