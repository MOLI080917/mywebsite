## 2. 导航方案

- **桌面**：固定顶栏，透明起始，滚动 >40px 后加近白半透明底 + 底部 1px 边框（毛玻璃 `backdrop-filter`，失败则纯色兜底）。左侧 MOLI 字标（点击回首屏），右侧锚点：About / Works / Skills / Path / Contact；当前所在分区对应项显示红色短下划线（ScrollTrigger 切换 `.is-active`）。
- **移动（≤768px）**：右侧汉堡按钮，点击展开近黑全屏菜单（scrim 遮罩），大字锚点纵向排列，红块指示；选后自动收起。
- 锚点平滑滚动用原生 `scroll-behavior:smooth` + `scroll-margin-top` 抵消固定导航；尊重 reduced-motion。
