## 2. 入选效果选型卡（6 个）

### ① typed-header —— Hero 文字解码入场
- **原始路径**：`001/typed-header（乱码加载-文字入场动画）/`
- **用在哪个区域**：Hero 首屏的品牌名 `MOLI` 与身份行（"中职计算机专业学生 / 前端方向"）。
- **解决什么 / 感受**：打开页面像程序在"解码"出名字，第一眼就立住"极客"人设；逐字落定也把视线聚焦到唯一焦点。
- **改编参数**：乱码字库改为 `01<>/\\{}[]=+*#_—` 与二进制 `01`；解码速度 28–40ms/字；品牌名只跑 1 轮、glitch 次数收敛，避免喧闹；循环改为"解码到正确文字即停"（不做打字机反复）。
- **配色融合**：解码中的乱码字符用中灰 `--color-text-sub`，落定后变近黑 `--color-text`；当前正在解码的字符用正红 `--color-accent`（焦点色，大号展示，满足 3:1）。
- **潜在风险 / 对策**：布局抖动 → 沿用源码的 preserve-layout 占位；读屏干扰 → 沿用 visually-hidden 完整文本 + `aria-hidden` 动画层；reduced-motion → 直接显示最终文字。

### ② gta6-scrolling-text-gradients —— 大字宣言分隔带
- **原始路径**：`001/gta6-inspired-scrolling-text-gradients（巨大文字-滚动渐变）/`
- **机制**：ScrollTrigger `scrub` 把滚动进度写进 CSS 变量 `--gy`，文字用 `background-clip:text` 做随滚动移动的径向渐变。
- **用在哪个区域**：About 与 Works 之间、Skills 与 Path 之间，各一条 ~50vh 的超大标语（如 "I BUILD THINGS." / "STILL LEARNING."）。
- **解决什么 / 感受**：在文字密集模块之间制造"高—低—高"节奏，用"锐利"的超大字号形成视觉换气。
- **改编参数**：字号沿用 clamp 巨型；去掉全部 oklch 彩色，改为 `近白→中灰→近黑` 的单色径向渐变，**中心高光带用唯一的正红**（随滚动扫过文字，属展示图形）；字重 900、字距收紧。
- **配色融合**：深色分区上用近白字 + 红色扫光；只用 transform/background-position，不改 layout。
- **风险 / 对策**：`background-clip:text` 兼容性 → 提供 `color` 兜底色；reduced-motion → 渐变固定、不随滚动变化。

### ③ diagonal-carousel —— 作品斜向卡片队列
- **原始路径**：`001/diagonal-carousel（点击触发的卡片画廊）/`
- **机制**：以 activeIndex 为中心，每张卡 `rotate=(i-active)*角度`、`scale=active?1:.6`、`y=(i-active)*偏移`，轨道整体 x 平移，spring 过渡 + 左右按钮与圆点。
- **用在哪个区域**：Works 作品区（4 个项目）。
- **解决什么 / 感受**：比普通网格更有"翻看作品"的仪式感和记忆点，斜向硬边贴合锐利。
- **改编参数**：**移除 React/Tailwind/Unsplash**，用原生 JS + GSAP 重写同一机制；卡片封面不用照片，改为近黑底 + 超大序号 `01–04` + 红色描边块的纯排版封面；角度 8°、非激活 scale .72、偏移 12%；点击任意卡/圆点/箭头切换。
- **配色融合**：卡片近白/深炭两种硬边卡，激活卡带红色硬投影 `--shadow-hard-accent`，标签用等宽字体灰字。
- **风险 / 对策**：移动端斜向易溢出 → 小屏改为纵向堆叠手风琴（同一数据、不同布局，不横溢）；键盘可达 → 按钮 focus 可见、支持左右方向键；reduced-motion → 关闭旋转只做显隐。

### ④ data-icons-float-nodes-connect —— 技能星座连线
- **原始路径**：`001/data-icons-float-nodes-connect-infographic-gsap（创意联系动画-交互）/`
- **用在哪个区域**：Skills 技能栈（深色反色分区）。
- **解决什么 / 感受**：中心是 MOLI，周围环绕"语言/前端/工具"三类技能节点，连线像知识网络，直观表达"技能成体系"，极客感强。
- **改编参数**：SVG `getTotalLength`+`strokeDashoffset` 让连线在进入视口时绘出；节点 back 弹性入场；保留 yoyo 微浮动（幅度收小到 6px，避免晕）；hover 放大 1.12。
- **配色融合**：深炭底，连线正红（焦点色，图形），节点近白描边/近白字，中心节点实心红底近黑字；只用调色板色。
- **风险 / 对策**：绝对定位节点在小屏重叠 → 768px 以下改为分组列表（连线隐藏，信息不丢）；连线长度需响应式 → viewBox 固定、SVG 等比缩放。

### ⑤ scroll-to-reveal-content —— 全局滚动揭示
- **原始路径**：`001/scroll-to-reveal-content（页面交流逻辑）/`
- **用在哪个区域**：全站每个分区的标题、段落、卡片、时间线条目（作为统一的入场基线）。
- **解决什么 / 感受**：引导视线随滚动逐块出现，避免一屏信息砸向用户；是"动效节奏"的慢速基底。
- **改编参数**：用 GSAP ScrollTrigger `batch`，`start: top 82%`，y:28→0 + opacity，stagger 0.1，时长 0.65，缓动统一 `--ease-out`；只动 transform/opacity。
- **配色融合**：不涉及颜色。
- **风险 / 对策**：内容被初始隐藏后若 JS 失败会看不到 → 用 `.no-js` 兜底：`<html class="no-js">`，JS 启动才加隐藏态；reduced-motion 全部直接显示。

### ⑥ navi-mouse —— 双层跟随光标
- **原始路径**：`001/navi-mouse（跟随鼠标的灵动精灵）/`
- **机制**：多层弹簧/插值，目标点即时、外圈以阻尼滞后跟随，并按速度轻微倾斜。
- **用在哪个区域**：全站桌面端（指针型设备）。
- **解决什么 / 感受**：一个跟手的小细节强化"锐利 + 有生命"的记忆点。
- **改编参数**：**去掉精灵翅膀/气泡/蓝色/发光**，只保留"内点即时 + 外圈 lerp 滞后"两层；内点 6px 近黑，外圈 34px 正红描边；悬停可交互元素时外圈放大并变红色半透明填充；用 `requestAnimationFrame` + lerp 0.16 实现。
- **配色融合**：仅近黑点 + 正红圈，严格在色板内。
- **风险 / 对策**：触屏无 hover → `matchMedia('(pointer:fine)')` 才启用，否则隐藏系统光标不被替换；reduced-motion/移动端 → 不启用；光标层 `pointer-events:none`、`aria-hidden`。

## 3. 动效节奏规划（快—慢—静）

| 时机 | 动效 | 节奏定位 |
|---|---|---|
| 页面加载（Hero） | ① 解码入场（快、抓注意） | **快** |
| 向下滚动经过各分区 | ⑤ 统一揭示（慢、引导） | **慢** |
| About→Works / Skills→Path | ② 超大宣言扫光（高、换气） | **快/高** |
| Works 交互 | ③ 斜向卡片切换（中、可玩） | **中** |
| Skills 进入 | ④ 连线绘制 + 微浮动（中→静） | **中→静** |
| 长段落 / 页脚 | 不设主导动效，仅 ⑤ 轻揭示 | **静（让眼睛休息）** |
| 全局指针 | ⑥ 光标跟随（持续但极轻） | 背景层 |

- **首屏**用①解码抓住注意力；**滚动中**用⑤引导视线、用②制造两次高潮；**交互元素**统一微交互（hover 提升、按钮按下、焦点环）；About 文案区与页脚保持静态。
- 每个区域只设一个主导动效：Hero=①、宣言带=②、Works=③、Skills=④，其余区域主导动效统一为⑤，不叠加。

- ③作品卡扇出、④星座、⑤滚动揭示等保留原选型，仅把驱动换成 GSAP（ScrollTrigger / DrawSVG），参数意图不变。
